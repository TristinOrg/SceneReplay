# Changelog

## [Unreleased]

- Removed reference-image-to-profile mapping; geometry authoring remains the responsibility of the implementation or external tool.
- Fixed preset-generated procedural meshes disappearing after converting the hierarchy to a Prefab.
- Removed the legacy Fantasy Hero, Humanoid Hero, Stylized Human, Noctis Chibi experiment, and character motion preview.

## [0.1.0] - 2026-08-01

- Added eleven cached primitive and procedural shape capabilities.
- Added reusable runtime generation, caller-budgeted batches, and performance diagnostics.
- Added the Stylized Human semantic template.
- Added Robot, Fantasy Hero, Workbench, Japanese Town, and Shibuya Crossing presets.
- Added transform-based animation examples for articulated models and furniture.
